My projects explore medical-history retrieval and financial market prediction. I'm strengthening my machine learning foundations while working on a **Real-Time Credit Risk Scoring Engine**.

## Featured projects

### Health Care GPT · Patient-scoped RAG
[Explore repository →](https://github.com/SyedBadiuzzaman/health_care_gpt)

A medical-history retrieval project with patient-scoped access and citation-bound historical summaries.

- Documents a retrieval pipeline with local MiniLM embeddings, chunking, and hybrid retrieval.
- Uses PostgreSQL and pgvector for indexed history, with FastAPI and JWT authorization.
- Includes retrieval and adversarial safety evaluation assets.

**Project stack:** Python · FastAPI · PostgreSQL · pgvector · Sentence Transformers · Gemini

### EQAP · Market prediction application
[Backend →](https://github.com/SyedBadiuzzaman/EQAP_Backend) · [Frontend →](https://github.com/SyedBadiuzzaman/EQAP_FrontEnd)

A machine learning application for exploring market data and price predictions across stocks, cryptocurrencies, and commodities.

- Backend documentation covers model serving, market-data retrieval, scheduled retraining, and MLflow tracking.
- React frontend presents interactive charts and forecast details.
- Connects a prediction API with a user-facing dashboard.

**Project stack:** Python · FastAPI · MLflow · Docker · React · JavaScript
